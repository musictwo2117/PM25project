# PM2.5 Forecasting in Bangkok with Machine Learning

การพยากรณ์ปริมาณฝุ่นละอองขนาดเล็กในอากาศ (PM2.5) ในพื้นที่กรุงเทพมหานคร ด้วยการเรียนรู้ของเครื่อง

โครงงานวิทยาการคอมพิวเตอร์ (01418499) ภาควิชาวิทยาการคอมพิวเตอร์ คณะวิทยาศาสตร์ มหาวิทยาลัยเกษตรศาสตร์ ภาคปลาย ปีการศึกษา 2565

- นางสาวณัฏฐพัชร์ ปุณณหิรัญย์ (6210450806)
- นางสาวนิภาวรรณ ประสพดี (6210451284)

อาจารย์ที่ปรึกษา: ผศ.ดร.อรวรรณ อิ่มสมบัติ, ดร.พิศุทธิ์ วิเศษสิงห์

รายงานฉบับเต็ม: [6210450806_6210451284_report.pdf](6210450806_6210451284_report.pdf)

## ภาพรวม

โครงงานนี้เปรียบเทียบโมเดล 4 แบบในการพยากรณ์ค่า PM2.5 รายวัน:

| โมเดล | แนวทางในโน้ตบุ๊ก |
| --- | --- |
| **LSTM** (Keras) | ใช้ค่า PM2.5 ย้อนหลัง (lag) ทำนายค่าถัดไป และพยากรณ์ล่วงหน้า 7 วัน |
| **Prophet** | ฟิตอนุกรมเวลาแล้วพยากรณ์ล่วงหน้า 180 วัน |
| **XGBoost** | ใช้ PM2.5 วันนี้ทำนาย PM2.5 วันพรุ่งนี้ |
| **LightGBM** | ใช้ปี เดือน วัน และวันในสัปดาห์เป็นฟีเจอร์ |

ข้อมูลเป็นค่ารายวันตั้งแต่ 1 ม.ค. 2018 (ประมาณ 1,765 วัน) จาก 3 สถานีในกรุงเทพฯ และค่าเฉลี่ยรวม

## โครงสร้างโปรเจกต์

```
rajthewee/        สถานีเขตราชเทวี   (dataAir.csv)
phrakanong/       สถานีเขตพระโขนง  (dataAir_phrakanong.csv)
dindang/          สถานีเขตดินแดง    (dataAir_dindang.csv)
all/              ค่าเฉลี่ยทุกเขต    (dataAir_newavg.csv)

```

แต่ละโฟลเดอร์เขตมีโน้ตบุ๊ก `LSTM_*`, `Prophet_*`, `XGBoost_*`, `LightGBM_*`

### คอลัมน์ในข้อมูล

`date`, `pm25`, `pm10`, `co`, `no2`, `avgT` (อุณหภูมิเฉลี่ย), `humid` (ความชื้นสัมพัทธ์), `pressure-monthly` (ความกดอากาศ), `windDir` (ทิศทางลม), `windSpd` (ความเร็วลม)
และแต่ละสถานีมีเพิ่มเติม: ราชเทวีมี `o3`, พระโขนงกับดินแดงมี `no` และ `nox`

## วิธีรัน

โน้ตบุ๊กทั้งหมดเขียนไว้สำหรับ **Google Colab** และอ่านข้อมูลจาก Google Drive

1. อัปโหลดไฟล์ CSV ขึ้น Google Drive
   - โน้ตบุ๊กในโฟลเดอร์เขตและ `all/` อ่านจาก `/content/drive/MyDrive/<ชื่อไฟล์>.csv`
   - โน้ตบุ๊กใน `conbine_graphs/` อ่านจาก `/content/drive/MyDrive/code/code/<โฟลเดอร์>/<ชื่อไฟล์>.csv`
     (คือโครงสร้างเดียวกับ repo นี้ วางไว้ใต้ `MyDrive/code/code/`)
2. เปิดโน้ตบุ๊กใน Colab แล้วกด Run all (จะมีหน้าต่างให้อนุญาตการเชื่อม Google Drive)
3. ถ้ารันนอก Colab ให้ลบ cell `drive.mount(...)` แล้วแก้ path ใน `pd.read_csv(...)` ให้ชี้ไปที่ไฟล์ในเครื่อง

แพ็กเกจที่ใช้: `pandas`, `numpy`, `matplotlib`, `scikit-learn`, `tensorflow`/`keras`, `prophet`, `xgboost`, `lightgbm` (มีใน Colab อยู่แล้ว ยกเว้น `prophet` ที่โน้ตบุ๊กติดตั้งให้เองด้วย `pip`)
